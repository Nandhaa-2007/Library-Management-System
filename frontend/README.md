# 📚 Library Management System

A web-based Library Book Lending Management System developed using the MERN Stack. This application helps manage books, library members, book lending, returns, loan history and fines.

## 🚀 Project Overview

The Library Management System makes library operations easier by providing a simple and user-friendly interface to manage book collections and lending activities.

## ✨ Features

- **Dashboard:** View total book titles, total copies, currently issued books, overdue loans and fines collected.
- **Add Books:** Add new books with title, author, ISBN, category and number of copies.
- **Book Management:** Edit and delete book details.
- **Issue Books:** Issue available books to library members.
- **Return Books:** Record book returns and calculate applicable fines.
- **Loan History:** View previous and current borrowing records.
- **Search Books:** Search books by title or author.
- **Category Filter:** Filter books based on categories.
- **Availability Filter:** Display only available books.
- **ISBN Validation:** Prevent duplicate ISBN entries.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Nandhaa-2007/Library-Management-System.git
```

### 2. Open the project

```bash
cd Library-Management-System
```

### 3. Install backend dependencies

```bash
cd backend
npm install
```

Configure your MongoDB connection and other required environment variables in the backend `.env` file.

### 4. Start the backend

Run the start command configured in the backend `package.json`.

### 5. Install frontend dependencies

Open another terminal:

```bash
cd frontend
npm install
```

### 6. Start the frontend

```bash
npm run dev
```

Open the local URL displayed in the terminal.

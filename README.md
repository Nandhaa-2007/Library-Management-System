# Library Management System

## Project Description
A web-based Library Management System developed using the MERN Stack to manage library book lending activities.

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript
- HTML
- CSS

## Project Structure
- frontend – React user interface
- backend – Node.js and Express.js server

## Features
- Library book lending management
- Book management
- User interface

## Installation and Setup

1. Clone the repository.
2. Install frontend dependencies using `npm install` inside the frontend folder.
3. Install backend dependencies using `npm install` inside the backend folder.
4. Configure environment variables.
5. Start the frontend and backend servers.
